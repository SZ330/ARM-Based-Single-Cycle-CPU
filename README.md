# ARM-Based-Single-Cycle-CPU

## Description

This repository contains an **ARM-based single-cycle CPU** implemented in **SystemVerilog** as part of EE 469.  
The processor executes each instruction in a **single clock cycle**, integrating instruction fetch, decode, execution, memory access, and write-back into a single datapath.

The design was developed to study:
- Single-cycle datapath organization
- ARM-style instruction execution
- Control signal generation
- Register file and memory integration
- Trade-offs between simplicity and clock performance
